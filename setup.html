Invite Setup

Setup

Get your laptop ready to make.

The M5Stack toolchain is a big download, up to 1 GB. Install it on a good connection before you arrive, not on the venue Wi‑Fi, and check that it works.

About 20 minutes. Commands are for macOS; Windows notes are along the way.

1The basics

Homebrew

The easiest way to install everything else.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Git, arduino-cli and a code editor

Git clones the starter repo. arduino-cli is what the Makefile uses to compile and flash your board.

brew install git arduino-cli
brew install --cask visual-studio-code

Then add the C/C++ extension in VS Code. Cursor works too.

On Windows: install Git and arduino-cli from their sites.

2M5Stack boards and libraries

The big one. Do this at home. It downloads the board definitions and the ESP32 toolchain.

arduino-cli config init
arduino-cli config add board_manager.additional_urls https://static-cdn.m5stack.com/resource/arduino/package_m5stack_index.json
arduino-cli core update-index
arduino-cli core install m5stack:esp32@3.3.10
arduino-cli lib install M5Unified M5GFX

The core is pinned to 3.3.10 on purpose: it has the StopWatch and StickS3 boards we use. Older cores don’t.

Check it worked

arduino-cli core list

You should see m5stack:esp32 at 3.3.10.

3An AI coding tool

Use whatever you like: Claude Code, Cursor, Copilot. New to this? Start with Claude Code.

Install

macOS / Linux
curl -fsSL https://claude.ai/install.sh | bash
Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex

Go

Open a terminal in your project folder and run claude. Sign in with a Claude Pro or Max plan, or an Anthropic Console account.

claude

Claude isn’t available in mainland China, but Claude Code can run on a Chinese model. Same tool, different brain: you point it at GLM (Zhipu) or DeepSeek.

a. Install Claude Code from a mirror

Needs Node.js 18 or newer. Don’t run claude yet.

brew install node
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com

b. Get a key and connect it. Pick one:

GLM Coding Plan (Zhipu). Sign up at open.bigmodel.cn, choose a Coding Plan, and create a key under API keys. Then run Zhipu’s helper, which writes the config for you:

npx @z_ai/coding-helper

DeepSeek, pay as you go. Create a key at platform.deepseek.com, then put this in ~/.claude/settings.json (on Windows, %USERPROFILE%\.claude\settings.json):

{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "your-deepseek-key",
    "API_TIMEOUT_MS": "3000000",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  }
}

c. Go

Open a new terminal in your project folder and run claude. If it asks “Do you want to use this API key?”, choose Yes. Type /status to check it’s talking to GLM or DeepSeek.

claude

4Drivers

  • StopWatch and StickS3 (the boards we use) need no driver on macOS, Windows or Linux. They use the ESP32-S3’s built-in USB.
  • Older M5 devices (Core Basic/Gray, M5StickC Plus, Atom Lite and similar) need the WCH CH9102/CH34x driver, and some need the Silicon Labs CP210x driver. Windows almost always needs them.
  • Apple Silicon Macs ask “Allow accessory to connect?” the first time you plug a board in. Click Allow. Otherwise the port never shows up.
  • Windows: the board shows up as a COM port. The Makefile expects macOS ports, so pass yours, like HANDHELD_PORT=COM5, or run arduino-cli directly.

5Nice to have

  • Python 3 for helper scripts and serial tools.
  • M5Burner, M5Stack’s app for flashing ready-made firmware. Handy for rescuing a bricked board.
  • UIFlow 2: blocks or MicroPython in the browser. A friendly start if you’d rather not touch C++.
  • A GitHub account (or the gh CLI), only if your team wants to push its work.

6Bring

  • A USB-C cable that carries data. Charge-only cables are the top reason a board “doesn’t show up.” Bring a spare.
  • A USB-C adapter or hub if your laptop has only one port.
