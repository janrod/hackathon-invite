2Set up your environment

Copy this prompt and paste it into your coding agent. It installs Homebrew, Git, arduino-cli, VS Code and the M5Stack toolchain, then checks that a build works. Up to 1 GB: do it on a good connection.

# Set up my laptop for the IDEO Shanghai AI Hackathon

You're setting up this computer for an M5Stack hardware hackathon. Work through the steps in order. Run the commands yourself and check that each one worked before moving on.

## Ground rules
- Skip anything that's already installed and working. Don't upgrade or remove what I have unless a step needs it.
- Ask me before anything that needs my password (sudo), and say what it's for.
- If downloads from GitHub or Homebrew are blocked or very slow (common in mainland China), switch to a mirror such as Tsinghua (TUNA) or USTC, and tell me.
- These steps are for macOS. On Windows, skip Homebrew and install the same tools with winget or their official installers.

## 1. Homebrew (macOS)
Check with `brew --version`. If it's missing, install it:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

The installer asks for my Mac password. If you can't enter it, ask me to run that command in Terminal and wait until I say it's done. Then add brew to the PATH as the installer says.

## 2. Git, arduino-cli and VS Code

```bash
brew install git arduino-cli
brew install --cask visual-studio-code   # skip if VS Code is already installed
code --install-extension ms-vscode.cpptools
```

## 3. M5Stack boards and libraries
This downloads up to 1 GB. Use core version 3.3.10 exactly: it has the StopWatch and StickS3 boards we use. If `config init` says a config already exists, that's fine, carry on.

```bash
arduino-cli config init
arduino-cli config add board_manager.additional_urls https://static-cdn.m5stack.com/resource/arduino/package_m5stack_index.json
arduino-cli core update-index
arduino-cli core install m5stack:esp32@3.3.10
arduino-cli lib install M5Unified M5GFX
```

## 4. Check that a build works
No board needs to be plugged in. Find the StickS3 board ID with `arduino-cli board listall m5stack`, then create `~/m5-hello/m5-hello.ino`:

```cpp
#include <M5Unified.h>
void setup() { M5.begin(); M5.Display.println("Hello, hackathon"); }
void loop() { M5.update(); }
```

Compile it, using the StickS3 FQBN from the list:

```bash
arduino-cli compile --fqbn <StickS3 FQBN> ~/m5-hello
```

## 5. Report back
Give me a short checklist: what you installed, the versions of arduino-cli and the m5stack:esp32 core, whether the test build passed, and anything I still need to do by hand.

Rather do it yourself? It’s readable: every command is in there, in order.

3Heads-up

The bits an agent can’t do for you.

  • Apple Silicon Macs ask “Allow accessory to connect?” the first time you plug a board in. Click Allow. Otherwise the port never shows up.
  • Windows: the board shows up as a COM port. The Makefile expects macOS ports, so pass yours, like HANDHELD_PORT=COM5.
  • StopWatch and StickS3 (the boards we use) need no driver. Older M5 devices (Core Basic/Gray, M5StickC Plus, Atom Lite) need the CH9102/CH34x driver or the CP210x driver, mostly on Windows.
  • Bring a USB-C cable that carries data. Charge-only cables are the top reason a board “doesn’t show up.” Bring a spare, and a USB-C hub if your laptop has one port.
